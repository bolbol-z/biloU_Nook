- Removed the duplicate `AppDelegate` from `BilouNookApp.swift`; the canonical
  delegate is `App/AppDelegate.swift`.
- Rewrote `Debug/DebugTools.swift` against the real `HotKeyManager.register()` and

- Debug tooling remains behind `#if DEBUG`; the nested duplicate `#if DEBUG`
  wrappers in the `Debug/` files were removed.
- `NotchRootView` body decomposed into `closedOverlays`, `notchContent`,
  `calibrationOverlay`, `handleAppear`, and `handlePhaseChange` to fix the
  type-check timeout caused by the large body.

  locals/unreachable code and the `MediaSnapshotRenderTests` slow expression).

  `AppIntents.framework` dependency, which is a system tool message.

### Settings
- Removed dead persisted keys: `handlerEnabled`, `handlerWidth`, `handlerHeight`,
  `displayMode`, `contentInDelay`, `contentStagger`, `scrubPause`,

### Modules
- `NotchPanel.panelSize(registry:)` now derives width from the widest enabled
  module instead of hardcoded module widths; empty registry falls back to
  `NotchPresets.open`.
- Added tests for registry-derived panel width and for the removed settings.
