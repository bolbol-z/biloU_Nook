# Step 7 — Smoke script and launch checks

## What changed

- `scripts/smoke.sh`
  - Runs `python3 scripts/check-project.py` before the build and reports
    `PROJECT PASS` / `PROJECT FAIL`.
  - Moves logs from `/tmp` to `build/logs/` so the script stays inside the
    repository:
    - `build/logs/smoke-build.log`
    - `build/logs/smoke-test.log`
  - Exits non-zero when project validation, build, or tests fail.
